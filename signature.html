How to Add This Signature to Your Mail Client

Select the employee above, click "Copy Formatted Signature", and follow the quick setup steps for your email platform:

Microsoft Outlook (Desktop)

  1. Click Copy Formatted Signature above.
  2. In Outlook, go to File → Options → Mail → Signatures.
  3. Click New and type a name (e.g. Makhaswa Official).
  4. Click inside the signature edit box and press Ctrl + V (Paste).
  5. Under Default Signature, select it for New Messages and Replies, then click Save.

Outlook Web (Office 365)

  1. Click Copy Formatted Signature above.
  2. Log into outlook.office.com and click the Settings (Gear) icon at top right.
  3. Go to Mail → Compose and reply → Email signature.
  4. Click + New signature, then press Ctrl + V.
  5. Set as default for new messages and click Save.

Gmail / Google Workspace

  1. Click Copy Formatted Signature above.
  2. In Gmail, click Settings (Gear) → See all settings.
  3. Scroll down to the Signature section.
  4. Click Create new and paste with Ctrl + V.
  5. Set it under Signature defaults and click Save Changes at the bottom.

Apple Mail & iPhone

  1. Mac: Mail → Settings → Signatures → Add new → uncheck "Always match my default font" → Cmd + V.
  2. iPhone: Copy signature → open Settings → Mail → Signature → paste → gently shake phone to choose "Undo Change Attributes" to keep original fonts and colors.
