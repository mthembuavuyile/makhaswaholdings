How to Add This Signature to Your Mail Client

Click the "Copy Formatted Signature" button at the top, then follow the quick instructions below for your email app:

Microsoft Outlook (Desktop)

  1. Click Copy Formatted Signature above.
  2. Open Outlook and go to File → Options → Mail → Signatures.
  3. Click New, give it a name (e.g., Makhaswa Official).
  4. Click inside the signature edit box and press Ctrl + V (Paste).
  5. Click Save and OK.

Outlook Web (Office 365)

  1. Click Copy Formatted Signature above.
  2. Open Outlook Web and click the Settings (Gear icon) at top right.
  3. Search for "Signature" → Email signature.
  4. Click New Signature, paste with Ctrl + V.
  5. Set as default for new messages and click Save.

Gmail / Google Workspace

  1. Click Copy Formatted Signature above.
  2. In Gmail, click Settings (Gear) → See all settings.
  3. Scroll down to the Signature section.
  4. Click Create new and paste with Ctrl + V.
  5. Select it under Signature defaults and click Save Changes at the bottom.

Apple Mail (Mac)

  1. Click Copy Formatted Signature above.
  2. Open Mail → Settings → Signatures.
  3. Click +, uncheck "Always match my default message font".
  4. Paste into the signature window with Cmd + V.
