Quick Setup in Outlook / Gmail

  1. Click Copy Formatted Signature above.
  2. In Outlook, go to File → Options → Mail → Signatures (or Gmail Settings → See all settings → Signature).
  3. Create a new signature, click into the editor box, and press Ctrl + V (Paste).
  4. Set as your default for new messages and replies, then click Save.
